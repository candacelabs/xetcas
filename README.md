# xetcas has moved

This repository was a generated snapshot of one folder of a private monorepo.
That monorepo now publishes as a single repository, and this snapshot is
frozen at its last export.

**The source is now [https://github.com/candacelabs/candace](https://github.com/candacelabs/candace), under `xetcas/`.**

Issues, discussion, and every future release live there. This repository is
archived and read-only; nothing further will be exported to it.
